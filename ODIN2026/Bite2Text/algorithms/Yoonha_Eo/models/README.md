# Final2 model installation

Run `python tools/download_models.py` from the repository root. The public release
contains all nine original checkpoints and the complete model runtime. Files are
installed in `models/final2` after archive and per-file checksum verification.

Do not commit the installed bundle. See `release/weights.json` for original hashes
and `NOTICE.md` for licensing. These are trained weights, not placeholder interfaces.
